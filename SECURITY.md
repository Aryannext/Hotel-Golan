# Seguridad

Se mantienen las correcciones de seguridad sobre `main`. Las versiones antiguas no tienen una política de soporte independiente.

## Reportar una vulnerabilidad

Use [Report a vulnerability](https://github.com/Aryannext/Hotel-Golan/security/advisories/new) para comunicarse de forma privada con el mantenedor. No publique tokens, contraseñas ni datos de huéspedes en issues, pull requests o logs.

Incluya los pasos para reproducir el problema, su impacto y el commit afectado, usando únicamente datos sintéticos. Si encuentra un secreto expuesto, revoque o rote la credencial; eliminarla del último commit no elimina su exposición en el historial.

## Controles automáticos

La configuración y los pasos para atender fallos están en [docs/automatizacion.md](docs/automatizacion.md). Un resultado verde confirma los controles ejecutados; no sustituye la revisión de autorización, datos personales, reglas contables ni del despliegue.
